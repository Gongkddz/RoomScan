留境 RoomScan 0.6.0-preview — Windows x64

解压整个 ZIP 到可写目录，双击 RoomScan.exe。
保留 _internal 和 .tools 文件夹。随包已提供 Python、核心服务依赖和 Brush。
首次启动需联网从官方 PyPI 安装并校验 PyCOLMAP 位姿引擎，此后可离线运行。
如下载失败，服务仍可配对和同步；检查网络后重新打开会重试安装。
无需安装 Python、CUDA 或 Android SDK；训练需要支持 Vulkan/WebGPU 的显卡及合适驱动。
手机安装配套 APK，电脑与手机连接同一局域网，首次扫描电脑窗口二维码配对。
Windows 防火墙仅允许专用网络上的应用访问；服务端口 8743，管理页仅绑定 127.0.0.1:8744。
不要将此服务直接暴露到公网。

数据、身份和日志写入程序目录下 .runtime；请勿公开分享此目录。
关闭窗口停止服务和重建。模型缓存后可在手机离线查看。
这是预览版本，精确 AR 放置、视觉惯性定位、碰撞和大场景 LOD 尚待实现。
Windows 程序未购买代码签名证书。
